# Flappy Original

Jogo no estilo Flappy Bird, desenvolvido em JavaScript com Canvas, com sprites em pixel art e rastro colorido no personagem.

## Estrutura

- `index.html`, `style.css`, `game.js`: jogo
- `assets`: imagens utilizadas
- `extract_cats.py`, `remove_bg.py`: scripts em Python usados para recortar e tratar as imagens

## Como executar

Abrir o arquivo `index.html` em um navegador.
